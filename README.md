# BorrowHub 🚀

BorrowHub is a comprehensive university equipment lending system designed to digitize inventory tracking, requests, approvals, asset assignments, and returns.

## 📌 Project Overview
This repository contains the complete engineering documentation and design models developed for BorrowHub, moving from concept discovery to requirements analysis, system workflows, relational database design, and architecture diagrams.

## 📂 Project Structure (`docs/`)
All professional documentation files are organized inside the `docs/` directory:
- **Product Requirements (PRD):** [`docs/PRD.md`](docs/PRD.md) — Complete functional & non-functional requirements, user roles, business rules, and acceptance criteria.
- **User Flow:** [`docs/user-flow.md`](docs/user-flow.md) — Detailed user journey and Mermaid workflow diagrams.
- **Database Design:** [`docs/database.dbml`](docs/database.dbml) & [`docs/ERD.md`](docs/ERD.md) — Relational schema design and Entity-Relationship definitions.
- **System Diagrams:** [`docs/diagrams/`](docs/diagrams/) — UML and system architecture diagrams (Domain Model, Use Case, Activity, Sequence, State, and Class diagrams).

## 🛠️ Methodology
The project follows a rigorous 7-stage software development methodology utilizing AI agents for documentation-first validation before implementation:
1. Requirements Discovery (Grill Me)
2. PRD Generation & Validation
3. User Flow Architecture
4. Git & GitHub Setup
5. Database Analysis & ERD (DBML)
6. UML & System Diagrams Generation
